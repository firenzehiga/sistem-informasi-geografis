Arsitektur Proyek Django (`webumkm`)

Aplikasi dibangun secara modular menggunakan arsitektur Model-View-Template (MVT) dengan pemisahan aplikasi per domain data spasial:

petaindonesia/

Mengelola portal beranda (`/`), peta dasar Indonesia (`/petasatu/`), Jabodetabek (`/petadua/`), Kampus STT-NF Depok (`/petatiga/`), 34 Provinsi (`/petaindonesia/provinsi/`), serta Choropleth Jawa (`/petaindonesia/petani_jawa/`).

gempabumi/

Menangani konsumsi data HTTP JSON dari API BMKG (15 gempa M 5.0+ terbaru), proteksi cadangan lokal `gempaterkini.json`, serta klasifikasi warna kedalaman sebelum dirender ke template.

static/json/

Direktori aset statis publik berisi `provinces.json`, statistik `petani_jawa.json`, poligon Jawa (`31–36.geojson`), dan 34 berkas GeoJSON batas provinsi Indonesia di subfolder `province/`.
